# Para ejecutarlo:

# 1. Instalar las librerías: `pip install -r requirements.txt`.
# 2. Descargar el dataset de https://doi.org/10.5281/zenodo.11295916. Colocar `LC_loans_granting_model_dataset.csv` en la carpeta `DatosUsados`.
# 3. Ejecutar `1_analisis.ipynb` y después `2_modelos.ipynb`. 
# 4. Ejecutar `3_flask.ipynb` y dejarlo funcionando.
# 5. Abrir otra terminal y ejecutar `streamlit run app.py`.
# Para utilizar el agente explicativo, hay que configurar una clave propia de OpenAI en un archivo `.env`
